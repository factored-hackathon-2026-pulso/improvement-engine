# Improvement domain

An autonomous service ingests bank history and treated platform observations, detects general signals, verifies hypotheses, proposes compatible Agent Core artifacts, evaluates them and learns through governed memory. The success is an unforced discovery and evaluated proposal, not a hardcoded complaint demo.

Signal is a measured observation; hypothesis is not causal proof; opportunity is supported and actionable; proposal is a versioned candidate; evaluation compares sealed baseline and candidate; release requires the external authority and confirmed receipt. Mitigation, closure and verified resolution are different.

Own Rust control/data/gates and service visibility. Consume external Agent Core runtime and provider routing; do not implement either. Platform attention/financial actions are outside our service. Missing external capabilities are visible, not fake successes.
