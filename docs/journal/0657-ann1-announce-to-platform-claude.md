# 0657 ANN1 announce_payload and the platform Announcer (UTC 2026-10-05T10:30Z, CLAUDE) [DONE]

Lane ANN1, branch `claude/ann1-announce-call` (from `origin/claude/align1-s22`; no PR, no merge dependency). Contract: platform PR 17 (`docs/platform/api/improvement-announce.md`, ADR 0007), item C2 of `docs/reports-claude/SPA_S22_ALIGNMENT_2026-10-05.md`.
- `registry_writer::announce::announce_payload(finding, proposal_ref, dossier)`: exact route body (`proposalId`, `title` <= 120, `problem` <= 600, `evidence` <= 600, `expectedEffect` <= 400, `evidenceLinks`), cut from the Spanish dossier `sections`. Bounds are checked locally with the platform's own email / 9+ digit rules: over-long text is cut at a word boundary, personal-data shapes are refused (`invalid_payload`, nothing sent). The route has no agent id or locale field, so neither is sent.
- Evidence links are opaque `CASE-<26 Crockford>` ids hashed from the finding `evidence_ref`; they have the shape the route demands but name NO real case (the engine holds aggregates only). Until the platform exposes real case ids, the bell link opens a case that does not exist.
- `Announcer`: runs only after agent-core delivered an `announced` proposal; `Idempotency-Key: announce:<proposal id>` (the platform is idempotent per proposal); 3 attempts with backoff on 5xx / transport errors, none on 401/404/422; outcome kept on the finding record as `platform_announce` = `platform_announced` | `platform_announce_failed:<invalid_payload|token_missing|unauthorized|not_found|rejected|unexpected_status|response_mismatch|unavailable>`; never fails the delivery. Allow-list `guard::platform_allowed`: POST to that one route.
- Config: `PULSO_PLATFORM_URL` (http, loopback or private IP / localhost only), `PULSO_PLATFORM_SERVICE_TOKEN` (process environment, redacted Debug, never in a record), `PULSO_ANNOUNCE_TO_PLATFORM` on|off: unset = ON only when URL and token are both set (live path), else OFF; `off` wins; `on` without URL or token refuses to start naming the variable.
- No `traceparent` / `baggage`: this base has no `core_client::trace` helper, so none is sent.
- Tests: `registry-writer/tests/announce.rs` (11), `pulso/tests/value_loop.rs` (3 new), `scripts/ann1/test_platform_double.py` (stdlib double of the route).
