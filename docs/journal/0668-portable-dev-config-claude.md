Lane PORTABLE, branch `claude/portable-dev-config` from `origin/main` 7222315f. Goal: a support-platform teammate runs the loop for a demo on their own machine (maybe Linux or macOS) without rewriting the scripts.
- Config: `scripts/dev-stack/DevConfig.ps1` (`Get-DevConfig`). Order: gitignored `devconfig.env` at the repo root (or `PULSO_DEVCONFIG`) > env var > default relative to the repo (`../agent-core`, `../llm-gateway`, `../support-platform`, `../.pulso-env/*.env`, `./target`) when it exists > the caller's legacy `D:\` default when it exists > the relative default (so the error names the portable path). The file accepts only an allowlist of names (paths, ports, podman names), so a key can not travel through it; an empty value is ignored except `PULSO_PODMAN_MACHINE=` (= default connection). `devconfig.example.env` is names only, all commented.
- Scripts wired to it (behaviour kept on the original machine: same paths through the legacy tier): `demo-loop/run.ps1`, `integrated-rig/{up,down,health,run_story}.ps1`, `o11y/langfuse_closure.ps1`, `dev-stack/stack.py` (podman selector `podman_conn_args`). Ports keep their existing `PULSO_RIG_*` / `PULSO_DEMO_*` variables, now also settable from the file.
- Portability: path literals use `/` (Join-Path), `.exe` suffix only on Windows, free RAM via CIM / `/proc/meminfo` MemAvailable / `vm_stat`, `cmd /c` vs `/bin/sh -c` for redirected children (`Set-DevShellCommand`), `taskkill` vs `pgrep`+`kill`, port check with a TcpListener instead of `Get-NetTCPConnection`, `python` or `python3`, podman without a machine on Linux (the old `pulso-dev-root` default stays only on Windows). New `scripts/dev-stack/doctor.ps1` (+ `Doctor.lib.ps1`): read-only preflight table with fix hints, exit 1 on a BLOCK, env files counted never read out. `docs/dev/QUICKSTART_LOCAL.md` for the teammate.
- Tests (RED first): `DevConfig.Tests.ps1` 22 (resolution order, file/env/default/legacy, exe suffix, podman args, meminfo/vm_stat parsers, mocked Linux/macOS RAM, shell command per OS, port check), `Doctor.Tests.ps1` 6, `tests/test_podman_connection.py` 4.
