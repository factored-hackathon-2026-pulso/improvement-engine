- What: seven metrics over the 1.3.0 platform events as six-field cell rows the existing cells sensor consumes: `P_DRAFT_REJECT` (draft acceptance, published as its complement because the sensor flags only higher-is-worse), `P_DRAFT_HEAVY_EDIT` (edit-distance bucket, aggregate only), `P_SUGG_NONE`, `P_SUGG_FAILED` (level risk, threshold 0.05 registered before data), `P_TOOL_USE` (tool mix as a case share), `P_TYPE_REASSIGN` (change away from a real type; the first `none -> T` labelling is not a reassignment), `P_ASSIST_ESCALATION`. Strata case_type, channel, language, release, agent (the AI agent, never a person), tool. No ids, no free text.
- Aggregator `scripts/aggregate/platform_event_cells.py`: k >= 10 (bank k rule and customer-hash halves reused), periods ALL/W1/W2 only (no month rows, no margins), DET1 hierarchy, and a NEW cross-signature rule: signatures of one metric share marginals, so a differencing attacker (row space of the partition identities over the withheld cells; every withheld cell and every sum of up to 3) runs inside `publish` and each unsafe determined combination is repaired by withholding ONE more published cell (the smallest of the finest identity touching it). Payload keys are allow-listed per type, enums closed, `agent`/`release`/`tool` values must be bounded tokens that are not platform ids (else a named discard); `assert_clean` is a hard output gate. Windows follow the case opening time (median split), so a release change leaves no stragglers in the other window.
- Sensor `steps::cells`: `Config::platform()` / `run_platform` / `steps_cli cells_platform`. Dims `language release agent tool` allowed. Contrast dimension by priority `case_type > release > agent > language > channel` (tool is a stratum, never a contrast): case_type x channel is compared with the same channel excluding its own type; release x agent with the other releases of the same agent. One comparison group per dimension signature, so two signatures of one metric never mix (the baseline total was keyed by metric and stratum only). Pooled support floor 200 (bank 500). One pre-registered level risk (`P_SUGG_FAILED`). The default config and every bank/E0 output are unchanged (`platform: false`; the 40 existing cells tests stay green).
