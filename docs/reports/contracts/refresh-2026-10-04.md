- Event catalog 1.2.0: 39 new admitted types, each with a data class (`operational`, `assistant`, `copilot`, `builder`), its payload keys, and the keys that carry free text (never forwarded): `case.priority_changed|rated|assistant_started|assistant_released`, `assistant.*` (6), `copilot.*` (2), `builder.*` (14), `escalation.*` (7), `call.*` (6). - Consistency: `platform-exporter` (catalog, per-type drop, policy, `KNOWN_UNREADABLE`), `db/` (`PRODUCT.cases` + 2 columns, `db/sql` regenerated), Rust `sources` (`policy.rs` columns, `monitor.rs` admitted list, drift tests against `event-catalog.json` and `policy.py`), Rust `control-api` embedded catalog test (version string only). `platform-sim` still models the 1.1.0 vocabulary (simulator parity is survey P8, not done here).
